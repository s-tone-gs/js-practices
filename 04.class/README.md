# アプリのセットアップ

このメモアプリではデータの保存先としてファイルを使用します。
以下の手順に従い、セットアップを行ってください

1. 任意のディレクトリ上からアプリをクローンする  
   `git clone -b my-class https://github.com/s-tone-gs/js-practices.git`
   を実行して下さい
1. `cloneを実行したディレクトリ/js-practices/04.class`に移動してください
1. ライブラリのインストール  
   `npm install`
1. データを保存するファイルとテーブルの作成  
   次のコマンドを実行してください  
    `node createTable.js`  
    エラーが出なければ完了です。
